## 2. Decisions for the coordinator

1. **Host context rows are `#host` lines.** check.py's `check_context` refuses any place outside `vendor/ui/js/` and
   `host/src/` (it does not visit `host/i18n`), so a plain row with a `host/i18n` place would be a check.py error.
   A `#host` line is a comment for check.py and the only thing check_rust reads. If check.py learns `host/i18n` as an
   unjudged part (`checked["host/i18n/"] = False` in `run()`), the prefix can go (check.py is not WU-FIX's).
2. **No new deferral text on the page.** The design's §5 text is the normal InfoBar, shown again by the restarted
   origin's start scan and now cleared by the resumed rescan. While a receiver still waits, the restarted page's
   button is enabled again; a click restarts the others once more and the waiting receiver ignores it (its restart
   is scheduled), GX1's accepted "harmless". A "File Explorer restarts after the copy" line would need a design text,
   two UI keys and state the new origin does not have (it missed the event while it restarted).
3. **pk.rs beyond n6:** the rescan hook had to live with the engine (`rescan` is private to pk.rs); all of it is in
   `// WU-FIX` blocks (field, initialiser, `init` call, three methods, `Drop`, one test). `update.rs` is untouched
   (the n6 key lives in `pk.rs install()`).
4. **Not covered by the resumed rescan:** an update owner that is a non-origin Settings (restarted at 300 ms, before
   the panel and the origin) scans too early and keeps a stale InfoBar until its next trigger (GX1 C2's general
   case); only a deferred receiver sends `shell.restartResumed`.
5. The execve check needs `--strace`; a run without it is not checked. The forbidden set adds `apt` and `pkcon` to
   the task's six (both forbidden by the hard rules; every harness session reaches them only through the stubs).
6. Files outside the explicit list: `tests/i18n/mock_settings.test.mjs` (+3 mock import cases, R3-UI's file; item 6's
   "with tests"), `tests/gnome/baseline/guard-selftest.json` (rewritten by the self-test run, 136 cases),
   `bus_tests.rs`'s n6 expectation (the F16 case; required by item 3), and my runs of others' scenarios in new
   directories `tests/gnome/scenarios/gx1-restart.wu-fix/`, `gx1-restart.en.wu-fix/`, `cross-r1.wu-fix/` (text
   output only in git, PNGs excluded). GW6/GW7: no `notes/claude/api-docs-wu-fix.md` exists in this worktree.
7. `tests/i18n` dumps: unchanged (nl 25886, en 25883 lines equal the baselines); no block changes.

**For Robin (unchanged):** `disks.unavailableBody`'s en drops "Disk Management doesn’t work:" (the `known` row,
D-G1b, the disks tables); the earlier D-G1b/D-G48 list stands.
