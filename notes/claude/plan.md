## Ground rules for every step

* **Dutch stays default and byte-identical**, except exact keys in `tests/i18n/BASELINE-CHANGES.{ui,rust,ext}`.
  Baselines at 3b898e6: `tests/i18n/baseline-{nl,en}.txt` (UI dump, 139 surfaces), `tests/i18n/rust-nl-frozen.tsv`
  and `rust-literals.tsv` (Rust), `tests/gnome/baseline/` (screenshots), the three Rust oracles.
* **The Windows 11 look is essential.** No CSS or layout change unless English text is proven to break the layout;
  then the smallest fix that keeps Dutch rendering identical.
* **Live session is off limits.** Robin runs this GNOME version right now. Never run a `win11-*` binary,
  `gnome-shell`, `gnome-extensions`, `gsettings set`, `dconf write`, `scripts/install.sh` or `uninstall.sh` outside
  the sandboxes (`tests/gnome/harness.py launch`, `tests/i18n/private.sh`, `tests/rust-sandbox/run-tests.sh`). Never
  touch `~/.local/bin/win11-*`, `~/.local/share/win11-gnome`, `~/.local/share/gnome-shell/extensions`,
  `~/.config/win11-gnome`, `~/.config/win11shell`, `~/.local/share/applications`, `~/.config/dconf`. Never signal
  processes you did not start. Never `--include-ignored` (an ignored test creates units on the real user manager).
* **No PackageKit transactions, no apt/pkcon/do-release-upgrade, not even a refresh.** No network downloads.
* **Heavy commands only through `tools/heavy.sh`** (contracts C8).
* **Path allowlist per step.** Edit only the files your step owns (tables below). Other steps work in the same tree at
  the same time: changes outside your allowlist are expected; changes inside it that you did not make mean a conflict,
  so stop and report. Nobody commits or switches branches; the coordinator commits after each round.
* **Keep work in the repo** (`tests/`, `tools/`, `notes/claude/`), never in /tmp except per C8.
